**Draco Download Manager** is a free, multi-connection download manager for Linux and Windows 11, with no accounts, trials or subscriptions. Created by **Md Hafijur Rahman**.

## Which file do I need?

| Your system | Download | Install |
|---|---|---|
| **Windows 11** | `DracoSetup-1.8.7.exe` | Double-click it. SmartScreen may warn because the app isn't code-signed: click **More info → Run anyway**. |
| **Ubuntu, Debian, Mint, Pop!_OS** | `draco-dm_1.8.7_all.deb` | `sudo apt install ./draco-dm_1.8.7_all.deb` |
| **Fedora** | `draco-dm-1.8.7-1.noarch.rpm` | `sudo dnf install ./draco-dm-1.8.7-1.noarch.rpm` |
| **Arch, Manjaro, EndeavourOS** | `draco-dm-1.8.7-1-any.pkg.tar.zst` | `sudo pacman -U draco-dm-1.8.7-1-any.pkg.tar.zst` |
| **Any Linux, fully self-contained** | `Draco-1.8.7-x86_64.flatpak` | `flatpak install --user Draco-1.8.7-x86_64.flatpak` |
| **Any Linux with GTK 4, one portable file** | `Draco-1.8.7-x86_64.AppImage` | `chmod +x Draco-1.8.7-x86_64.AppImage`, then double-click it |
| **Anything else** | `draco-dm-1.8.7-linux.tar.gz` | Unpack it and run `./install.sh` (no root needed) |

Browser extension: `draco-extension-chromium-1.8.7.zip` (Chrome, Edge, Brave, Opera, Vivaldi) or `draco-extension-firefox-1.8.7.zip`. Unzip it, open the browser's extensions page, turn on **Developer mode** and click **Load unpacked**. Draco also places a copy in `Documents/Draco Browser Extension` on first start.

### Notes per format

- **AppImage:** includes yt-dlp and ffmpeg, but uses your system's GTK 4 and libadwaita (standard on GNOME, Ubuntu 23.10+, Fedora 39+). If they're missing, it tells you the exact install command.
- **Flatpak:** brings everything with it (GNOME runtime, yt-dlp, ffmpeg). Because of the sandbox, connect the browser extension with **Connect to Draco** in its popup, and downloads are saved to your Downloads folder. "Shut down when done" isn't available in the Flatpak.
- **Windows installer:** includes yt-dlp and ffmpeg.
