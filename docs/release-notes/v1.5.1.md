**Draco Download Manager** is a free, multi-connection download manager for Linux and Windows 11, with no accounts, trials or subscriptions. Created by **Md Hafijur Rahman**.

## Which file do I need?

| Your system | Download | Install |
|---|---|---|
| **Windows 11** | `DracoSetup-1.5.1.exe` | Double-click it. SmartScreen may warn because the app isn't code-signed: click **More info → Run anyway**. |
| **Ubuntu, Debian, Mint, Pop!_OS** | `draco-dm_1.5.1_all.deb` | `sudo apt install ./draco-dm_1.5.1_all.deb` |
| **Fedora** | `draco-dm-1.5.1-1.noarch.rpm` | `sudo dnf install ./draco-dm-1.5.1-1.noarch.rpm` |
| **Arch, Manjaro, EndeavourOS** | `draco-dm-1.5.1-1-any.pkg.tar.zst` | `sudo pacman -U draco-dm-1.5.1-1-any.pkg.tar.zst` |
| **Any Linux, fully self-contained** | `Draco-1.5.1-x86_64.flatpak` | `flatpak install --user Draco-1.5.1-x86_64.flatpak` |
| **Any Linux with GTK 4, one portable file** | `Draco-1.5.1-x86_64.AppImage` | `chmod +x Draco-1.5.1-x86_64.AppImage`, then double-click it |
| **Anything else** | `draco-dm-1.5.1-linux.tar.gz` | Unpack it and run `./install.sh` (no root needed) |

Browser extension: `draco-extension-chromium-1.5.1.zip` (Chrome, Edge, Brave, Opera, Vivaldi) or `draco-extension-firefox-1.5.1.zip`. Unzip it, open the browser's extensions page, turn on **Developer mode** and click **Load unpacked**. Draco also places a copy in `Documents/Draco Browser Extension` on first start.

### Notes per format

- **AppImage:** includes yt-dlp and ffmpeg, but uses your system's GTK 4 and libadwaita (standard on GNOME, Ubuntu 23.10+, Fedora 39+). If they're missing, it tells you the exact install command.
- **Flatpak:** brings everything with it (GNOME runtime, yt-dlp, ffmpeg). Because of the sandbox, connect the browser extension with **Connect to Draco** in its popup, and downloads are saved to your Downloads folder. "Shut down when done" isn't available in the Flatpak.
- **Windows installer:** includes yt-dlp and ffmpeg.

## New in 1.5.1

- **Check where a file goes, and keep one folder for everything.** The File Info dialog now says plainly *"Will be saved in: …"* before you start. Tick **"Always save downloads to this folder from now on"** and every new download (browser captures, videos and quick capture included) goes to that folder, ignoring category folders, until you reset it. You can change or reset it in **Options → Save To → Always save to one folder** (**Choose…** / **Reset to default**).
- **No more double downloads in Brave.** Brave sometimes refused to pause its own download for a moment, so the file was downloaded by both Brave and Draco. The extension now keeps trying to pause, and if the browser already finished its copy by the time Draco takes over, that duplicate is removed. **Update the extension:** on the extensions page, click **Reload** on Draco's card. If you loaded it from a downloaded zip, load the new `draco-extension-chromium-1.5.1.zip` (or the `Documents/Draco Browser Extension/chrome` folder, which Draco keeps up to date).
- Field names in the File Info dialog are no longer cut off.

## Features

- **Faster downloads:** up to 32 connections per file, with dynamic segmentation that keeps every connection busy until the end.
- **Pause, resume, crash recovery:** downloads continue exactly where each connection stopped.
- **Browser integration** for Chrome, Edge, Brave, Opera, Vivaldi and Firefox, including cookies for logged-in downloads. Draco checks a link before taking it over; links that only work in the browser (such as Google Drive) stay with the browser.
- **Video:** a "⬇ Download this video" button on the player. Choose a quality with its size shown first, or use **Quick capture** (`Alt+Shift+D`). YouTube and 1000+ sites via yt-dlp, and HLS streams shown with resolution, size and length.
- **Subtitles:** embedded in the video and saved as `.srt`.
- **Queues and scheduler,** site grabber, batch downloads, clipboard watcher, categories, speed limiter, virus-scan hook.
- **14 themes,** including a *Retro Gray* classic-desktop look, with matching icon styles.
