**Draco Download Manager** is a free, multi-connection download manager for Linux and Windows 11, with no accounts, trials or subscriptions. Created by **Md Hafijur Rahman**.

## Which file do I need?

| Your system | Download | Install |
|---|---|---|
| **Windows 11** | `DracoSetup-1.9.1.exe` | Double-click it. SmartScreen may warn because the app isn't code-signed: click **More info → Run anyway**. |
| **Ubuntu, Debian, Mint, Pop!_OS** | `draco-dm_1.9.1_all.deb` | `sudo apt install ./draco-dm_1.9.1_all.deb` |
| **Fedora** | `draco-dm-1.9.1-1.noarch.rpm` | `sudo dnf install ./draco-dm-1.9.1-1.noarch.rpm` |
| **Arch, Manjaro, EndeavourOS** | `draco-dm-1.9.1-1-any.pkg.tar.zst` | `sudo pacman -U draco-dm-1.9.1-1-any.pkg.tar.zst` |
| **Any Linux, fully self-contained** | `Draco-1.9.1-x86_64.flatpak` | `flatpak install --user Draco-1.9.1-x86_64.flatpak` |
| **Any Linux with GTK 4, one portable file** | `Draco-1.9.1-x86_64.AppImage` | `chmod +x Draco-1.9.1-x86_64.AppImage`, then double-click it |
| **Anything else** | `draco-dm-1.9.1-linux.tar.gz` | Unpack it and run `./install.sh` (no root needed) |

Browser extension: `draco-extension-chromium-1.9.1.zip` (Chrome, Edge, Brave, Opera, Vivaldi) or `draco-extension-firefox-1.9.1.zip`. Unzip it, open the browser's extensions page, turn on **Developer mode** and click **Load unpacked**. Draco also places a copy in `Documents/Draco Browser Extension` on first start.

### Notes per format

- **AppImage:** includes yt-dlp, ffmpeg and aria2, but uses your system's GTK 4 and libadwaita (standard on GNOME, Ubuntu 23.10+, Fedora 39+). If they're missing, it tells you the exact install command.
- **Flatpak:** brings everything with it (GNOME runtime, yt-dlp, ffmpeg, aria2). Because of the sandbox, connect the browser extension with **Connect to Draco** in its popup, and downloads are saved to your Downloads folder. "Shut down when done" isn't available in the Flatpak.
- **Windows installer:** includes yt-dlp, ffmpeg and aria2.
- **.deb:** installs aria2 automatically. The .rpm and Arch packages recommend it (`sudo dnf install aria2` / `sudo pacman -S aria2`).

## New in 1.9.1

- **See your torrent peers.** The details pane and the Status tab now show how many peers you are connected to and how many of them are seeds, for example "7 peers (3 seeds)". While none are found yet it says "Looking for peers…".
- **Peer list.** For torrents, the Connections tab lists every connected peer with its address, download and upload speed, and how much of the torrent it has ("seed" for complete peers).
- **Clearer magnet start.** While a magnet link is still fetching its file list, Draco says "Getting the file list…" and already shows the peers it has found, instead of a bare "Connecting…".
- **Better peer discovery.** Draco now gives aria2 a DHT starting node, so magnet links can find peers through DHT on a fresh install, not only through trackers.
- **More seeds, steadier speed.** Draco now opens its torrent port on your router with UPnP, so peers on the internet can connect to you, not only you to them. Each torrent keeps one fixed port instead of a random one, and the mapping is removed when the torrent stops or Draco quits. Turn it off in Preferences → Torrents → "Open the port on the router (UPnP)". It can't help if your internet provider puts you behind its own NAT (carrier-grade NAT); ask them for a public IP address in that case.
- **Public trackers.** Public torrents and magnet links also ask a list of well-known public trackers for peers, so a link with few or dead trackers still finds seeds. Private torrents are never sent to them. Switch: Preferences → Torrents → "Add public trackers to public torrents".
- **Keeps looking for peers.** Draco now connects to up to 100 peers per torrent and keeps searching for more while the speed is below 10 MB/s, instead of settling for the first few.
