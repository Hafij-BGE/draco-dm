**Draco Download Manager** is a free, multi-connection download manager for Linux and Windows 11, with no accounts, trials or subscriptions. Created by **Md Hafijur Rahman**.

## Which file do I need?

| Your system | Download | Install |
|---|---|---|
| **Windows 11** | `DracoSetup-1.9.0.exe` | Double-click it. SmartScreen may warn because the app isn't code-signed: click **More info → Run anyway**. |
| **Ubuntu, Debian, Mint, Pop!_OS** | `draco-dm_1.9.0_all.deb` | `sudo apt install ./draco-dm_1.9.0_all.deb` |
| **Fedora** | `draco-dm-1.9.0-1.noarch.rpm` | `sudo dnf install ./draco-dm-1.9.0-1.noarch.rpm` |
| **Arch, Manjaro, EndeavourOS** | `draco-dm-1.9.0-1-any.pkg.tar.zst` | `sudo pacman -U draco-dm-1.9.0-1-any.pkg.tar.zst` |
| **Any Linux, fully self-contained** | `Draco-1.9.0-x86_64.flatpak` | `flatpak install --user Draco-1.9.0-x86_64.flatpak` |
| **Any Linux with GTK 4, one portable file** | `Draco-1.9.0-x86_64.AppImage` | `chmod +x Draco-1.9.0-x86_64.AppImage`, then double-click it |
| **Anything else** | `draco-dm-1.9.0-linux.tar.gz` | Unpack it and run `./install.sh` (no root needed) |

Browser extension: `draco-extension-chromium-1.9.0.zip` (Chrome, Edge, Brave, Opera, Vivaldi) or `draco-extension-firefox-1.9.0.zip`. Unzip it, open the browser's extensions page, turn on **Developer mode** and click **Load unpacked**. Draco also places a copy in `Documents/Draco Browser Extension` on first start.

### Notes per format

- **AppImage:** includes yt-dlp, ffmpeg and aria2, but uses your system's GTK 4 and libadwaita (standard on GNOME, Ubuntu 23.10+, Fedora 39+). If they're missing, it tells you the exact install command.
- **Flatpak:** brings everything with it (GNOME runtime, yt-dlp, ffmpeg, aria2). Because of the sandbox, connect the browser extension with **Connect to Draco** in its popup, and downloads are saved to your Downloads folder. "Shut down when done" isn't available in the Flatpak.
- **Windows installer:** includes yt-dlp, ffmpeg and aria2.
- **.deb:** installs aria2 automatically. The .rpm and Arch packages recommend it (`sudo dnf install aria2` / `sudo pacman -S aria2`).

## New in 1.9.0

- **Torrents and magnet links.** Paste a magnet link or open a `.torrent` file (or a link to one) and Draco downloads it with aria2. Before starting you can pick which files to download and rename the folder. Pause, resume, progress and speed work like any other download.
- **Seeding.** A finished torrent keeps sharing until it reaches a ratio (default 1.0) or a time limit (default 60 minutes), both set in **Preferences → Torrents**, together with an upload limit and the listening port. Removing a torrent from the list keeps its files; cancelling an unfinished one deletes the partial data.
- **Browser extension.** Clicked magnet links go to Draco when capturing is on (Alt+click leaves them to the browser), and `.torrent` files are captured like other downloads.
- **Opens torrents for you.** On Linux Draco registers for `.torrent` files and `magnet:` links. The Windows installer offers the same as a ticked option, removed again on uninstall.
- **No extra app needed.** aria2 comes with the Windows installer, AppImage and Flatpak, and the .deb installs it automatically.

Privacy: like any BitTorrent client, your IP address is visible to the other peers of a torrent. On Windows the firewall may ask once whether aria2c may accept connections; allowing it gives more peers.
