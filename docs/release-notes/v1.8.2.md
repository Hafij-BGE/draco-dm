**Draco Download Manager** is a free, multi-connection download manager for Linux and Windows 11, with no accounts, trials or subscriptions. Created by **Md Hafijur Rahman**.

## Which file do I need?

| Your system | Download | Install |
|---|---|---|
| **Windows 11** | `DracoSetup-1.8.2.exe` | Double-click it. SmartScreen may warn because the app isn't code-signed: click **More info → Run anyway**. |
| **Ubuntu, Debian, Mint, Pop!_OS** | `draco-dm_1.8.2_all.deb` | `sudo apt install ./draco-dm_1.8.2_all.deb` |
| **Fedora** | `draco-dm-1.8.2-1.noarch.rpm` | `sudo dnf install ./draco-dm-1.8.2-1.noarch.rpm` |
| **Arch, Manjaro, EndeavourOS** | `draco-dm-1.8.2-1-any.pkg.tar.zst` | `sudo pacman -U draco-dm-1.8.2-1-any.pkg.tar.zst` |
| **Any Linux, fully self-contained** | `Draco-1.8.2-x86_64.flatpak` | `flatpak install --user Draco-1.8.2-x86_64.flatpak` |
| **Any Linux with GTK 4, one portable file** | `Draco-1.8.2-x86_64.AppImage` | `chmod +x Draco-1.8.2-x86_64.AppImage`, then double-click it |
| **Anything else** | `draco-dm-1.8.2-linux.tar.gz` | Unpack it and run `./install.sh` (no root needed) |

Browser extension: `draco-extension-chromium-1.8.2.zip` (Chrome, Edge, Brave, Opera, Vivaldi) or `draco-extension-firefox-1.8.2.zip`. Unzip it, open the browser's extensions page, turn on **Developer mode** and click **Load unpacked**. Draco also places a copy in `Documents/Draco Browser Extension` on first start.

### Notes per format

- **AppImage:** includes yt-dlp and ffmpeg, but uses your system's GTK 4 and libadwaita (standard on GNOME, Ubuntu 23.10+, Fedora 39+). If they're missing, it tells you the exact install command.
- **Flatpak:** brings everything with it (GNOME runtime, yt-dlp, ffmpeg). Because of the sandbox, connect the browser extension with **Connect to Draco** in its popup, and downloads are saved to your Downloads folder. "Shut down when done" isn't available in the Flatpak.
- **Windows installer:** includes yt-dlp and ffmpeg.

## Fixed in 1.8.2

- **No more double downloads in Brave.** Brave could ignore the extension's request to cancel its own copy while it was still choosing the file name, so the file was downloaded by both Brave and Draco. The extension now pauses Brave's copy right away, keeps cancelling it until it stops, and if Brave finished it anyway, deletes that copy and removes it from Brave's download list. Downloads that skip Brave's file-name step are now caught too.

**Update the extension:** on `brave://extensions` (or your browser's extensions page), click **Reload** on Draco's card. App Hub 1.7.1 and later also download the new extension for you.

## Features

- **Faster downloads:** up to 32 connections per file, with dynamic segmentation that keeps every connection busy until the end.
- **Pause, resume, crash recovery:** downloads continue exactly where each connection stopped.
- **Browser integration** for Chrome, Edge, Brave, Opera, Vivaldi and Firefox, including cookies for logged-in downloads. Draco checks a link before taking it over; links that only work in the browser (such as Google Drive) stay with the browser.
- **Video:** a "⬇ Download this video" button on the player. Choose a quality with its size shown first, or use **Quick capture** (`Alt+Shift+D`). YouTube and 1000+ sites via yt-dlp, and HLS streams shown with resolution, size and length.
- **Subtitles:** embedded in the video and saved as `.srt`.
- **Queues and scheduler,** site grabber, batch downloads, clipboard watcher, categories, speed limiter, virus-scan hook.
- **14 themes,** including a *Retro Gray* classic-desktop look, with matching icon styles.
