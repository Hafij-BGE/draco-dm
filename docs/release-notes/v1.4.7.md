**Draco Download Manager** is a free, multi-connection download manager for Linux and Windows 11, with no accounts, trials or subscriptions. Created by **Md Hafijur Rahman**.

This is a Windows-only update. Linux users can stay on 1.4.6.

## Which file do I need?

| Your system | Download | Install |
|---|---|---|
| **Windows 11** | `DracoSetup-1.4.7.exe` | Double-click it. SmartScreen may warn because the app isn't code-signed: click **More info → Run anyway**. |

Browser extension: `draco-extension-chromium-1.4.7.zip` (Chrome, Edge, Brave, Opera, Vivaldi) or `draco-extension-firefox-1.4.7.zip`. Unzip it, open the browser's extensions page, turn on **Developer mode** and click **Load unpacked**. If you already loaded the extension from `Documents\Draco Browser Extension`, Draco updates that copy when 1.4.7 starts: just click **Reload** on the extension's card.

## Fixed in 1.4.7 (Windows)

- **Old downloads no longer pop up when you open the browser.** When the browser starts it replays its download history, and Draco used to open a File Info dialog or a progress window for every past download. Now only downloads that have just started are taken over.
- **Only one copy of Draco runs.** Opening Draco while it was still starting (or the browser starting it at the same moment) could start a second copy, giving two Draco windows working on the same download list. A second launch now waits for the first copy and brings its window forward instead.
