**Draco Download Manager** is a free, multi-connection download manager for Linux and Windows 11, with no accounts, trials or subscriptions. Created by **Md Hafijur Rahman**.

## Which file do I need?

| Your system | Download | Install |
|---|---|---|
| **Windows 11** | `DracoSetup-1.9.2.exe` | Double-click it. SmartScreen may warn because the app isn't code-signed: click **More info → Run anyway**. |
| **Ubuntu, Debian, Mint, Pop!_OS** | `draco-dm_1.9.2_all.deb` | `sudo apt install ./draco-dm_1.9.2_all.deb` |
| **Fedora** | `draco-dm-1.9.2-1.noarch.rpm` | `sudo dnf install ./draco-dm-1.9.2-1.noarch.rpm` |
| **Arch, Manjaro, EndeavourOS** | `draco-dm-1.9.2-1-any.pkg.tar.zst` | `sudo pacman -U draco-dm-1.9.2-1-any.pkg.tar.zst` |
| **Any Linux, fully self-contained** | `Draco-1.9.2-x86_64.flatpak` | `flatpak install --user Draco-1.9.2-x86_64.flatpak` |
| **Any Linux with GTK 4, one portable file** | `Draco-1.9.2-x86_64.AppImage` | `chmod +x Draco-1.9.2-x86_64.AppImage`, then double-click it |
| **Anything else** | `draco-dm-1.9.2-linux.tar.gz` | Unpack it and run `./install.sh` (no root needed) |

Browser extension: `draco-extension-chromium-1.9.2.zip` (Chrome, Edge, Brave, Opera, Vivaldi) or `draco-extension-firefox-1.9.2.zip`. Unzip it, open the browser's extensions page, turn on **Developer mode** and click **Load unpacked**. Draco also places a copy in `Documents/Draco Browser Extension` on first start.

### Notes per format

- **AppImage:** includes yt-dlp, ffmpeg and aria2, but uses your system's GTK 4 and libadwaita (standard on GNOME, Ubuntu 23.10+, Fedora 39+). If they're missing, it tells you the exact install command.
- **Flatpak:** brings everything with it (GNOME runtime, yt-dlp, ffmpeg, aria2). Because of the sandbox, connect the browser extension with **Connect to Draco** in its popup, and downloads are saved to your Downloads folder. "Shut down when done" isn't available in the Flatpak.
- **Windows installer:** includes yt-dlp, ffmpeg and aria2.
- **.deb:** installs aria2 automatically. The .rpm and Arch packages recommend it (`sudo dnf install aria2` / `sudo pacman -S aria2`).

## New in 1.9.2

Bug fixes:

- **Removing a torrent never deletes your own files.** Draco only removes the files it downloaded itself, and file names are taken literally, so a name with wildcard characters can no longer match other files.
- **Safer resume.** Before continuing a partial download, Draco checks that the file on the server hasn't changed (ETag / Last-Modified, sent as If-Range). If it has, the download starts over instead of producing a corrupt file.
- **Logins stay on their own site.** Credentials are stripped when a download is redirected to a different host, and saved site logins only apply to the exact host they were saved for.
- **Browser connection errors are reported.** The native messaging host now replies with an error instead of going silent when something goes wrong.
- **Bridge input checks.** The loopback bridge answers 400 Bad Request to a missing or invalid Content-Length.
- **Steadier segments.** A segment's retry counter resets once it makes progress again, so long downloads with occasional hiccups no longer give up early.
- **Header injection fixed.** CR/LF characters are stripped from headers passed to ffmpeg.
