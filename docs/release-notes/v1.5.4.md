**Draco Download Manager** is a free, multi-connection download manager for Linux and Windows 11, with no accounts, trials or subscriptions. Created by **Md Hafijur Rahman**.

## Which file do I need?

| Your system | Download | Install |
|---|---|---|
| **Windows 11** | `DracoSetup-1.5.4.exe` | Double-click it. SmartScreen may warn because the app isn't code-signed: click **More info → Run anyway**. |
| **Ubuntu, Debian, Mint, Pop!_OS** | `draco-dm_1.5.4_all.deb` | `sudo apt install ./draco-dm_1.5.4_all.deb` |
| **Fedora** | `draco-dm-1.5.4-1.noarch.rpm` | `sudo dnf install ./draco-dm-1.5.4-1.noarch.rpm` |
| **Arch, Manjaro, EndeavourOS** | `draco-dm-1.5.4-1-any.pkg.tar.zst` | `sudo pacman -U draco-dm-1.5.4-1-any.pkg.tar.zst` |
| **Any Linux, fully self-contained** | `Draco-1.5.4-x86_64.flatpak` | `flatpak install --user Draco-1.5.4-x86_64.flatpak` |
| **Any Linux with GTK 4, one portable file** | `Draco-1.5.4-x86_64.AppImage` | `chmod +x Draco-1.5.4-x86_64.AppImage`, then double-click it |
| **Anything else** | `draco-dm-1.5.4-linux.tar.gz` | Unpack it and run `./install.sh` (no root needed) |

Browser extension: `draco-extension-chromium-1.5.4.zip` (Chrome, Edge, Brave, Opera, Vivaldi) or `draco-extension-firefox-1.5.4.zip`. Unzip it, open the browser's extensions page, turn on **Developer mode** and click **Load unpacked**. Draco also places a copy in `Documents/Draco Browser Extension` on first start.

### Notes per format

- **AppImage:** includes yt-dlp and ffmpeg, but uses your system's GTK 4 and libadwaita (standard on GNOME, Ubuntu 23.10+, Fedora 39+). If they're missing, it tells you the exact install command.
- **Flatpak:** brings everything with it (GNOME runtime, yt-dlp, ffmpeg). Because of the sandbox, connect the browser extension with **Connect to Draco** in its popup, and downloads are saved to your Downloads folder. "Shut down when done" isn't available in the Flatpak.
- **Windows installer:** includes yt-dlp and ffmpeg.

## What's new since 1.5.0

**Choose and keep your download folder**
- The File Info dialog says plainly *"Will be saved in: …"* before you start.
- Tick **"Always save downloads to this folder from now on"** and every new download goes there (browser captures, videos and quick capture included) until you reset it in **Options → Save To → Always save to one folder** (**Choose…** / **Reset to default**).
- The extension's **Quick capture** switch now says that it skips the "where to save" dialog. Turn it off to confirm the folder for every download.

**Long Google Drive downloads finish**
- They no longer stop near the end with *"Server stopped honouring byte ranges"*. Google renews its login cookies every few minutes; the extension now passes the browser's current cookies to Draco every minute and whenever they change, and a download that stopped this way continues by itself.
- When a site answers with a sign-in page, Draco says so and never saves that page over your file.

**No double downloads in Brave**
- If the browser starts the same download twice, or refuses to pause it at first, the browser's copy is now cancelled (or removed if it already finished) once Draco has the download.

**The browser extension updates itself again**
- If your Documents folder setting is `$HOME/`, Draco wrote its extension copy to your home folder instead of `Documents/Draco Browser Extension`, so the extension you loaded stayed on an old version. Fixed.

**Update the extension:** on the extensions page, click **Reload** on Draco's card (load `Documents/Draco Browser Extension/chrome` if you haven't yet). The card should show **1.5.4**.

### Earlier in 1.5.0 and 1.4.x

- At most two YouTube downloads run at once, and Draco retries when YouTube is busy (1.4.8). yt-dlp uses Node.js when deno isn't installed, so all qualities are found.
- **Runs in the background** when the window is closed, with no taskbar entry (1.4.6). Turn it off in **Options → General**.
- Windows: old browser downloads no longer pop up on browser start, and only one copy of Draco runs (1.4.7).
- Theme names no longer use other products' names (*Retro Gray*, *Soft Light*, *Nightshade*, *Arctic Frost*, *Sand Light*, *Deep Teal*).
- Linux packages for every major distro (`.rpm`, Arch, Flatpak, AppImage, `.tar.gz`) next to the `.deb` and the Windows installer.
- One "N downloads complete" notification that clears when you open Draco.

## Features

- **Faster downloads:** up to 32 connections per file, with dynamic segmentation that keeps every connection busy until the end.
- **Pause, resume, crash recovery:** downloads continue exactly where each connection stopped.
- **Browser integration** for Chrome, Edge, Brave, Opera, Vivaldi and Firefox, including cookies for logged-in downloads. Draco checks a link before taking it over; links that only work in the browser (such as Google Drive) stay with the browser.
- **Video:** a "⬇ Download this video" button on the player. Choose a quality with its size shown first, or use **Quick capture** (`Alt+Shift+D`). YouTube and 1000+ sites via yt-dlp, and HLS streams shown with resolution, size and length.
- **Subtitles:** embedded in the video and saved as `.srt`.
- **Queues and scheduler,** site grabber, batch downloads, clipboard watcher, categories, speed limiter, virus-scan hook.
- **14 themes,** including a *Retro Gray* classic-desktop look, with matching icon styles.
